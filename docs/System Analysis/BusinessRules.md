تغطي هذه الوثيقة جميع قواعد العمل (Business Rules) لنظام CarCarePlus وهي مرجع إلزامي لفريق التطوير والتحليل والاختبار. الأولوية العالية تعني أن القاعدة يجب تطبيقها في المرحلة الأولى من التطوير.

**BR-01 - قواعد الحجز**

| **رقم القاعدة** | **القاعدة**                                         | **الأولوية** |
| --------------- | --------------------------------------------------- | ------------ |
| **BR-01.1**     | لا يمكن حجز خدمة بدون سيارة مضافة في الحساب         | **عالية**    |
| **BR-01.2**     | الحجز الفوري له سعر أعلى من الحجز المجدول           | **عالية**    |
| **BR-01.3**     | لا يمكن تعديل الطلب قبل نصف ساعة من الموعد          | **عالية**    |
| **BR-01.4**     | لا يمكن حجز موعد في وقت ماضٍ                        | **عالية**    |
| **BR-01.5**     | الحجز الجماعي المتعدد مخصص لحسابات الشركات فقط      | **عالية**    |
| **BR-01.6**     | لا يُغلق الطلب نهائياً بدون تأكيد الدفع             | **عالية**    |
| **BR-01.7**     | لا يمكن تعديل الطلب بعد إسناده للموظف مباشرة        | **عالية**    |
| **BR-01.8**     | الطلب الفوري له أولوية أعلى من الطلبات المجدولة     | **عالية**    |
| **BR-01.9**     | تذكير تلقائي للعميل قبل موعد الخدمة بساعة واحدة     | **متوسطة**   |
| **BR-01.10**    | يُمنع تعارض الحجوزات عبر Concurrency Lock في النظام | **عالية**    |

**BR-02 - قواعد التسعير**

| **رقم القاعدة** | **القاعدة**                                                                   | **الأولوية** |
| --------------- | ----------------------------------------------------------------------------- | ------------ |
| **BR-02.1**     | السعر يُحسب تلقائياً بناءً على نوع الخدمة ونوع السيارة                        | **عالية**    |
| **BR-02.2**     | كل كيلومتر يتجاوز المسافة الأساسية له تكلفة إضافية تُحددها الإدارة            | **عالية**    |
| **BR-02.3**     | أيام العطل الرسمية وأيام الجمعة لها تعرفة سعر مختلفة                          | **عالية**    |
| **BR-02.4**     | الخدمة خارج أوقات العمل الرسمية أغلى من أوقات العمل                           | **عالية**    |
| **BR-02.5**     | الخدمة في الليل لها تعرفة أعلى من الخدمة النهارية                             | **عالية**    |
| **BR-02.6**     | خدمة VIP تضيف نسبة إضافية على السعر الأساسي                                   | **متوسطة**   |
| **BR-02.7**     | يتم إعادة حساب السعر تلقائياً عند أي تغيير في تفاصيل الطلب                    | **عالية**    |
| **BR-02.9**     | الخصم عند تعارض الحجوزات لا يتجاوز 25% من السعر الأساسي                       | **متوسطة**   |
| **BR-02.10**    | إذا كانت تكلفة موظف إضافي أقل من الخصم المقدم يُرسل موظف إضافي بدلاً من الخصم | **متوسطة**   |

**BR-03 - قواعد الدفع**

| **رقم القاعدة** | **القاعدة**                                                              | **الأولوية** |
| --------------- | ------------------------------------------------------------------------ | ------------ |
| **BR-03.1**     | الدفع كاش عند اللقاء على ارض الواقع او نقاط او باقات ويكون مباشرة        | **عالية**    |
| **BR-03.2**     | قيمة تحويل النقاط للدفع تُحددها الإدارة ولا يمكن تعديلها من قبل المستخدم | **عالية**    |
| **BR-03.3**     | النقاط لا تُحوَّل إلى نقد نهائياً                                        | **عالية**    |
| **BR-03.4**     | الباقة المنتهية الصلاحية لا تُقبل كطريقة دفع                             | **عالية**    |
| **BR-03.5**     | الدفع النقدي يُؤكده الموظف في النظام بعد استلام المبلغ من العميل         | **عالية**    |
| **BR-03.6**     | النقاط تُضاف لحساب العميل فقط بعد إتمام الدفع بنجاح                      | **عالية**    |
| **BR-03.7**     | يُصدر إيصال إلكتروني لكل عملية دفع ناجحة                                 | **عالية**    |
| **BR-03.10**    | فاتورة المواد الإضافية تُعالج بشكل منفصل عن الخدمة الأساسية              | **متوسطة**   |

**BR-04 - قواعد الموظفين**

| **رقم القاعدة** | **القاعدة**                                                         | **الأولوية** |
| --------------- | ------------------------------------------------------------------- | ------------ |
| **BR-04.1**     | كل طلب يُسند لموظف واحد فقط - لا يمكن تعيين أكثر من موظف لنفس الطلب | **عالية**    |
| **BR-04.2**     | الأدمن هو المسؤول الوحيد عن إسناد الطلبات للموظفين                  | **عالية**    |
| **BR-04.4**     | GPS الموظف يجب أن يكون مفعلاً أثناء أوقات العمل                     | **عالية**    |
| **BR-04.5**     | لا يُغلق الطلب قبل تأكيد الدفع من الموظف في حالة الدفع النقدي       | **عالية**    |
| **BR-04.6**     | يتم حساب تلقائيا اقرب فرع متاح حسب الموقع الجغرافي                  | **عالية**    |
| **BR-04.7**     | حالة الموظف تتحدث تلقائياً (متاح، مشغول، في الطريق، في الموقع)      | **عالية**    |
| **BR-04.8**     | لا يُمكن تنفيذ خدمتين في نفس الوقت لنفس الموظف                      | **عالية**    |

**BR-05 - قواعد المواد الإضافية**

| **رقم القاعدة** | **القاعدة**                                                                                                           | **الأولوية** |
| --------------- | --------------------------------------------------------------------------------------------------------------------- | ------------ |
| **BR-05.1**     | لا يستخدم الموظف أي مواد إضافية بدون موافقة صريحة من العميل                                                           | **عالية**    |
| **BR-05.2**     | يرسل الموظف قائمة المواد المقترحة للعميل كإشعار قبل الاستخدام                                                         | **عالية**    |
| **BR-05.3**     | العميل يحق له رفض أي مادة مقترحة أو تعديل الكميات                                                                     | **عالية**    |
| **BR-05.4**     | تُصدر فاتورة منفصلة مستقلة للمواد الإضافية                                                                            | **متوسطة**   |
| **BR-05.5**     | لا يمكن اضافة مواد اضافية عبر فاتور ثانية قبل مرور نصف ساعة من الموعد المحدد                                          | **متوسطة**   |
| **BR-05.6**     | جميع المواد المستخدمة تُسجَّل في النظام وتُخصم من المخزون تلقائياً                                                    | **عالية**    |
| **BR-05.7**     | طلب المواد له مدة صلاحية محددة للرد - ينتهي تلقائياً عند انقضائها<br><br>ولا يتم اضافتها في حال عدم الرد بعد وقت محدد | **متوسطة**   |

**BR-06 - قواعد الاسترداد والإلغاء**

| **رقم القاعدة** | **القاعدة**                                                       | **الأولوية** |
| --------------- | ----------------------------------------------------------------- | ------------ |
| **BR-06.1**     | إلغاء الطلب قبل الإسناد للموظف يستوجب استرداداً كاملاً            | **عالية**    |
| **BR-06.2**     | الإلغاء بعد الإسناد وقبل بدء التنفيذ يخضع لسياسة الإلغاء المعتمدة | **عالية**    |
| **BR-06.3**     | لا يُقبل الإلغاء بعد بدء تنفيذ الخدمة فعلياً                      | **عالية**    |
| **BR-06.4**     | في حال الدفع بالنقاط او الباقات فانها تعاد كما هي عند الالغاء     | **عالية**    |
| **BR-06.5**     | عند تعديل الموعد يُعاد حساب السعر                                 | **متوسطة**   |
| **BR-06.6**     | سبب الإلغاء يجب أن يُسجَّل في النظام من قبل مُنفّذ الإلغاء        | **متوسطة**   |

**BR-07 - قواعد النقاط والباقات**

| **رقم القاعدة** | **القاعدة**                                                              | **الأولوية** |
| --------------- | ------------------------------------------------------------------------ | ------------ |
| **BR-07.1**     | النقاط تُكسب فقط عند إتمام الطلب ونجاح الدفع                             | **متوسطة**   |
| **BR-07.2**     | قيمة ونسبة كسب النقاط تحددها الإدارة فقط                                 | **متوسطة**   |
| **BR-07.3**     | النقاط لها تاريخ انتهاء صلاحية - تنتهي إذا لم تُستخدم خلال المدة المحددة | **متوسطة**   |
| **BR-07.4**     | لا يمكن تعديل رصيد النقاط يدوياً من قبل المستخدم                         | **عالية**    |
| **BR-07.5**     | الباقة تُفعَّل فور إتمام الدفع وتُربط بحساب المستخدم مباشرة              | **متوسطة**   |
| **BR-07.6**     | الباقة النشطة لا يمكن حذفها أو إلغاؤها من قبل الإدارة                    | **متوسطة**   |
| **BR-07.7**     | إشعار تلقائي يُرسل للعميل عند اقتراب انتهاء صلاحية الباقة                | **متوسطة**   |

**BR-08 - قواعد التقييم**

| **رقم القاعدة** | **القاعدة**                                                       | **الأولوية** |
| --------------- | ----------------------------------------------------------------- | ------------ |
| **BR-08.1**     | التقييم مرة واحدة فقط لكل خدمة - لا يمكن التعديل بعد الإرسال      | **عالية**    |
| **BR-08.2**     | التقييم من 1 إلى 5 نجوم مع تعليق نصي اختياري                      | **عالية**    |
| **BR-08.3**     | تقييم الموظف يُحدَّث تلقائياً بالمتوسط المتراكم بعد كل تقييم جديد | **عالية**    |
| **BR-08.4**     | لا يمكن للموظف تعديل أو حذف التقييمات المرتبطة به                 | **عالية**    |
| **BR-08.5**     | التقييم مرتبط بخدمة محددة ولا يمكن إرساله قبل اكتمال الخدمة       | **عالية**    |

**BR-09 - قواعد الصلاحيات والحسابات**

| **رقم القاعدة** | **القاعدة**                                                        | **الأولوية** |
| --------------- | ------------------------------------------------------------------ | ------------ |
| **BR-09.1**     | حسابات الشركات تُنشأ من قبل الإدارة فقط - العميل لا يستطيع إنشاءها | **عالية**    |
| **BR-09.2**     | تتبع GPS الموظفين متاح للأدمن والسوبر أدمن فقط                     | **عالية**    |
| **BR-09.3**     | الأدمن يدير مستخدمي وطلبات فرعه فقط - لا صلاحية على الفروع الأخرى  | **عالية**    |
| **BR-09.4**     | السوبر أدمن يملك صلاحية كاملة على جميع الفروع والبيانات            | **عالية**    |
| **BR-09.5**     | العميل لا يرى بيانات عملاء أو موظفين آخرين                         | **عالية**    |
| **BR-09.6**     | لا يمكن حذف مستخدم لديه طلبات نشطة في النظام                       | **عالية**    |
| **BR-09.7**     | الحساب يُقفل مؤقتاً بعد 5 محاولات دخول فاشلة متتالية               | **عالية**    |
| **BR-09.8**     | الجلسة تنتهي تلقائياً بعد 30 دقيقة من عدم النشاط                   | **متوسطة**   |

**BR-10 - قواعد الجدولة الذكية**

| **رقم القاعدة** | **القاعدة**                                                         | **الأولوية** |
| --------------- | ------------------------------------------------------------------- | ------------ |
| **BR-10.1**     | عند تعارض حجزين يُعرض وقت بديل مع خصم على العميل الثاني             | **عالية**    |
| **BR-10.2**     | إذا رفض العميل الثاني الوقت البديل يُشعر العميل الأول ليختار بديلاً | **متوسطة**   |
| **BR-10.3**     | حساب جدوى موظف إضافي: إذا التكلفة < الخصم يُرسل موظف إضافي          | **متوسطة**   |
| **BR-10.4**     | الطلب الفوري له أولوية أعلى من الطلبات المجدولة في قائمة الانتظار   | **عالية**    |
| **BR-10.5**     | لا يمكن تحويل الطلب الفوري لمجدول بعد تأكيده إلا بإلغاء             | **عالية**    |

**BR-11 - قواعد المخزون**

| **رقم القاعدة** | **القاعدة**                                                     | **الأولوية** |
| --------------- | --------------------------------------------------------------- | ------------ |
| **BR-11.1**     | المخزون يُحدَّث تلقائياً عند استخدام مواد في أي خدمة            | **عالية**    |
| **BR-11.2**     | تنبيه تلقائي يُرسل للأدمن عند انخفاض مادة عن الحد الأدنى المحدد | **عالية**    |
| **BR-11.3**     | لا يمكن للموظف استخدام مواد غير مخزَّنة أو غير مصرح بها         | **عالية**    |
| **BR-11.4**     | طلبات شراء المواد ترسل من الأدمن للسوبر أدمن للموافقة           | **متوسطة**   |
| **BR-11.5**     | لا يُنفَّذ طلب الشراء قبل الموافقة الرسمية من السوبر أدمن       | **متوسطة**   |

**BR-12 - قواعد الذكاء الاصطناعي**

| **رقم القاعدة** | **القاعدة**                                                            | **الأولوية** |
| --------------- | ---------------------------------------------------------------------- | ------------ |
| **BR-12.1**     | الحلول التي يقترحها الذكاء الاصطناعي إرشادية فقط وليست تشخيصاً نهائياً | **متوسطة**   |
| **BR-12.2**     | إذا فشل البوت في تحديد المشكلة يُحوَّل العميل تلقائياً لفني بشري       | **عالية**    |
| **BR-12.3**     | قواعد الذكاء الاصطناعي يحددها ويعدلها السوبر أدمن فقط                  | **متوسطة**   |
| **BR-12.5**     | يقترح النظام أقرب ورشة مناسبة حسب نوع المشكلة التي تم تشخيصها          | **متوسطة**   |

**BR-13 - قواعد المساعدة على الطريق**

| **رقم القاعدة** | **القاعدة**                                                             | **الأولوية** |
| --------------- | ----------------------------------------------------------------------- | ------------ |
| **BR-13.1**     | GPS يجب أن يكون مفعلاً لإرسال طلب المساعدة أو يُطلب إدخال الموقع يدوياً | **عالية**    |
| **BR-13.2**     | طلبات المساعدة على الطريق تحظى بأعلى أولوية في النظام                   | **عالية**    |
| **BR-13.3**     | لا يمكن إلغاء طلب الطوارئ بعد الإرسال إلا خلال فترة محدودة جداً         | **عالية**    |
| **BR-13.4**     | بيانات السائق/الموظف تُرسل للعميل فور قبول الطلب                        | **عالية**    |
| **BR-13.5**     | يمكن للعميل اختيار أكثر من مشكلة معروفة في نفس طلب المساعدة             | **متوسطة**   |

**BR-14 - قواعد التسوية النقدية**

| **رقم القاعدة** | **القاعدة**                                                              | **الأولوية** |
| --------------- | ------------------------------------------------------------------------ | ------------ |
| **BR-14.1**     | الموظف ملزم بتسليم جميع المبالغ النقدية المحصَّلة للأدمن في نهاية الدوام | **عالية**    |
| **BR-14.2**     | الأدمن يصدر إيصال استلام رسمي عند تسلّم المبالغ من الموظف                | **عالية**    |
| **BR-14.3**     | يُطابق النظام المبالغ النقدية المستلمة مع الطلبات المكتملة يومياً        | **عالية**    |
| **BR-14.4**     | عند رفض الأدمن التسوية تُعاد فتح دورة المراجعة وتُسجَّل الأسباب          | **متوسطة**   |
| **BR-14.5**     | لا يُغلق اليوم المالي قبل الموافقة على جميع تسويات النقد                 | **عالية**    |

**دليل الأولويات**

| **الأولوية** | **التعريف**                                                                      |
| ------------ | -------------------------------------------------------------------------------- |
| **عالية**    | يجب تطبيقها في المرحلة الأولى من التطوير. مخالفتها يُعدّ خللاً حرجاً في النظام.  |
| **متوسطة**   | مهمة وتُطبَّق في المرحلة الأولى أو الثانية. مخالفتها قد تؤثر على تجربة المستخدم. |
| **منخفضة**   | تُطبَّق في المراحل المتقدمة. لا تأثير حرج إذا تأخرت.                             |
