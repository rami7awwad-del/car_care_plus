# أولاً: حالات استخدام العميل الشخصي (Customer-Personal)

## UC-01 - تسجيل حساب جديد (Register)

| **Use Case ID**      | UC-01                                                                                                                                                                                                                                                                                            |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Use Case Name**    | تسجيل حساب جديد (Register)                                                                                                                                                                                                                                                                       |
| **Actor**            | Guest User                                                                                                                                                                                                                                                                                       |
| **Description**      | يقوم العميل بإنشاء حساب جديد في النظام لأول مرة                                                                                                                                                                                                                                                  |
| **Priority**         | عالية                                                                                                                                                                                                                                                                                            |
| **Trigger**          | المستخدم يختار تسجيل حساب جديد                                                                                                                                                                                                                                                                   |
| **Preconditions**    | المستخدم غير مسجل في النظام - يمتلك بريد إلكتروني صالح                                                                                                                                                                                                                                           |
| **Postconditions**   | يتم إنشاء حساب جديد للعميل ويصبح قادراً على تسجيل الدخول                                                                                                                                                                                                                                         |
| **Main Flow**        | 1\. يفتح المستخدم تطبيق الجوال<br><br>2\. يختار تسجيل حساب جديد<br><br>3.يدخل البيانات الاساسية (الاسم \| البريد الالكتروني \| ومعلومات ااضافية )<br><br>4\. يوافق على الشروط والأحكام<br><br>5\. يضغط على 'تسجيل'<br><br>6\. يستقبل رسالة تفعيل عبر البريد أو SMS<br><br>7\. يكتمل إنشاء الحساب |
| **Alternative Flow** | \- إذا كان البريد مسجلاً مسبقاً: يظهر رسالة خطأ وتُطلب بيانات مختلفة - إذا كانت كلمة المرور ضعيفة: يُطلب تقوية كلمة المرور                                                                                                                                                                       |
| **Exception Flow**   | فشل ارسال كود التفعيل \| انتهاء صلاحية الكود \| انقطاع الأنترنت اثناء التسجيل                                                                                                                                                                                                                    |
| **Business Rules**   | يجب ان يكون البريد الالكتروني فريدا<br><br>كلمة المرور لا تقل عن 8 احرف وتحتوي رموزا وارقام<br><br>رقم الهاتف يجب ان يكون صالحا                                                                                                                                                                  |

## UC-02 - تسجيل الدخول (Login)

| **Use Case ID**      | UC-02                                                                                                                                                                                                                                                                               |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use Case Name**    | تسجيل الدخول (Login)                                                                                                                                                                                                                                                                |
| **Actor**            | Customer-Personal                                                                                                                                                                                                                                                                   |
| **Description**      | يقوم العميل المسجل بتسجيل دخوله إلى النظام                                                                                                                                                                                                                                          |
| **Priority**         | عالية                                                                                                                                                                                                                                                                               |
| **Trigger**          | المستخدم يختار تسجيل الدخول                                                                                                                                                                                                                                                         |
| **Preconditions**    | المستخدم لديه حساب مسجل ومفعّل<br><br>النظام متاح ويعمل بشكل طبيعي                                                                                                                                                                                                                  |
| **Postconditions**   | يتم تسجيل دخول العميل والانتقال للصفحة الرئيسية                                                                                                                                                                                                                                     |
| **Main Flow**        |  يفتح المستخدم التطبيق<br><br> يختار "تسجيل الدخول"<br><br> يدخل البريد الإلكتروني أو رقم الجوال<br><br> يدخل كلمة المرور<br><br> يضغط على "دخول"<br><br> يقوم النظام بالتحقق من صحة البيانات<br><br> يتم تسجيل الدخول بنجاح<br><br> يتم توجيه المستخدم إلى الصفحة الرئيسية |
| **Alternative Flow** | \- إذا كانت البيانات خاطئة: تظهر رسالة 'بيانات غير صحيحة' - بعد 5 محاولات فاشلة: يتم قفل الحساب مؤقتاً                                                                                                                                                                              |
| **Exception Flow**   |  بعد 5 محاولات فاشلة: <br>→ يتم قفل الحساب مؤقتًا لمدة محددة<br><br> في حال نسيان كلمة المرور: <br>→ يمكن للمستخدم اختيار "نسيت كلمة المرور" والانتقال لعملية الاستعادة<br><br> في حال وجود مشكلة في الاتصال: <br>→ تظهر رسالة "تحقق من اتصال الإنترنت"                          |
| **Business Rules**   |  يجب أن تتطابق بيانات الدخول مع البيانات المخزنة في النظام<br><br> يتم تشفير كلمة المرور قبل مقارنتها<br><br> الحد الأقصى لمحاولات تسجيل الدخول الفاشلة هو 5 مرات<br><br> يتم قفل الحساب مؤقتًا بعد تجاوز عدد المحاولات                                                         |

## UC-04 - إعادة تعيين كلمة المرور (Reset Password)

| **Use Case ID**      | UC-04                                                                                                                                                                                                                                                    |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use Case Name**    | إعادة تعيين كلمة المرور (Reset Password)                                                                                                                                                                                                                 |
| **Actor**            | Customer-Personal                                                                                                                                                                                                                                        |
| **Description**      | يقوم العميل باستعادة أو تغيير كلمة المرور المنسية                                                                                                                                                                                                        |
| **Priority**         | عالية                                                                                                                                                                                                                                                    |
| **Trigger**          | اختيار المستخدم "نسيت كلمة المرور"                                                                                                                                                                                                                       |
| **Preconditions**    | المستخدم لديه حساب مسجل                                                                                                                                                                                                                                  |
| **Postconditions**   | يتم تغيير كلمة المرور بنجاح                                                                                                                                                                                                                              |
| **Main Flow**        | 1\. يضغط على 'نسيت كلمة المرور'<br><br>2\. يدخل البريد الإلكتروني أو رقم الجوال<br><br>3\. يستقبل رمز التحقق<br><br>4\. يدخل الرمز<br><br>5\. يدخل كلمة المرور الجديدة<br><br>6\. يتم تحديث كلمة المرور                                                  |
| **Alternative Flow** | \- إذا لم يكن البريد مسجلاً: تظهر رسالة خطأ - إذا انتهت صلاحية الرمز: يتم إعادة إرساله                                                                                                                                                                   |
| **Exception Flow**   |  إذا لم يكن البريد أو رقم الجوال مسجلاً: تظهر رسالة خطأ<br><br> إذا انتهت صلاحية رمز التحقق: يُطلب إعادة الإرسال<br><br> في حال إدخال رمز تحقق غير صحيح: تظهر رسالة "رمز غير صحيح"<br><br> في حال فشل إرسال الرمز: تظهر رسالة "فشل إرسال رمز التحقق" |
| **Business Rules**   |  جب أن يكون الحساب موجودًا في النظام<br><br> رمز التحقق صالح لفترة زمنية محددة<br><br> كلمة المرور الجديدة يجب أن تستوفي شروط الأمان (8 أحرف على الأقل)<br><br> لا يمكن استخدام كلمة المرور القديمة                                                  |

## UC-05 - إدارة الملف الشخصي (Manage Profile)

| **Use Case ID**      | UC-05                                                                                                                                                                                                      |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use Case Name**    | إدارة الملف الشخصي (Manage Profile)                                                                                                                                                                        |
| **Actor**            | Customer-Personal                                                                                                                                                                                          |
| **Description**      | يقوم العميل بعرض وتعديل بياناته الشخصية                                                                                                                                                                    |
| **Priority**         | متوسطة                                                                                                                                                                                                     |
| **Trigger**          | دخول المستخدم إلى صفحة الملف الشخصي                                                                                                                                                                        |
| **Preconditions**    | العميل مسجل الدخول                                                                                                                                                                                         |
| **Postconditions**   | يتم حفظ التعديلات على الملف الشخصي                                                                                                                                                                         |
