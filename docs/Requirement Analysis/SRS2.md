**1\. المقدمة :**

**1.1 الغرض :**

يتمثل الغرض الأساسي من النظام في توفير منصة مركزية تتيح للعملاء (أفراد وشركات) حجز خدمات غسيل وصيانة السيارات، وطلب المساعدة على الطريق، وإدارة أساطيل المركبات، مع تزويد الإدارة بأدوات متكاملة لمراقبة الأداء والمخزون والمالية. يمتد النظام ليشمل تطبيقات الهواتف المحمولة للعملاء والموظفين، ولوحة تحكم إدارية على الويب، لضمان تدفق المعلومات لحظياً بين جميع المكونات.

| **_نوع التطبيق_**  | **_المستخدم_**               |
| ------------------ | ---------------------------- |
| Mobile Application | Customer - Personal          |
| Web Application    | Customer - Company           |
| Mobile Application | Employee (Washer / Mechanic) |
| Web Dashboard      | Admin (Branch Manager)       |
| Web Dashboard      | Super Admin                  |

**1.2 نطاق العمل:**

- **Mobile application :**

تطبيق موبايل شامل لإدارة خدمات السيارات (غسيل، فحص، مساعدة على الطريق) يمكّن العميل من حجز الخدمات فوراً أو مجدولاً، وتتبع موقع الموظف والدفع بعدة طرق والتواصل مع بوت ذكاء اصطناعي لتشخيص مشاكل السيارة

كما يوفر التطبيق للموظفين (غسيل وميكانيكيين) واجهة لإدارة مهامهم، وتحديث حالة الخدمة والمواد المستخدمة، وتأكيد استلام المدفوعات النقدية، وطلب مواد إضافية من العميل أو الشركة، مع استلام إشعارات فورية بتكليف المهام.

**_The app works on both Android and iOS systems._**

- **Web application :  
   **منصة مخصصة للشركات تسمح بإدارة أسطول السيارات وحجز خدمات متعددة في طلب واحد (حجز جماعي). يمكن للشركة إضافة سياراتها (رقم اللوحة، الموديل)، وتحديد تواريخ بدء وانتهاء الخدمة، واختيار نوع الخدمة لكل سيارة بشكل منفصل. يقوم النظام بحساب التكلفة الإجمالية وإصدار فاتورة موحدة .
- **Admin Web Dashboard :  
   **لوحة تحكم ويب تمكن مدير الفرع من إدارة جميع عمليات فرعه فقط. يستطيع إضافة وحذف وتعديل مستخدمي فرعه (موظفين وعملاء) يدير الطلبات الواردة إلى فرعه .
- **: Super Admin Web Dashboard**

لوحة تحكم عليا تتحكم في النظام بالكامل جميع الفروع، جميع المستخدمين، جميع الإعدادات .

**1.3 نظرة عامة :**

تم تنظيم هذه الوثيقة في أقسام تصف ميزات النظام، الواجهات الخارجية، المتطلبات الوظيفية وغير الوظيفية، ومتطلبات البيانات اللازمة لتنفيذ النظام .

**2\. الوصف العام :**

**2.1 منظور المنتج:**

نظام إدارة خدمات السيارات هو تطبيق جديد قائم بذاته (standalone) يعمل على الجوال والويب. يتفاعل مع خدمات خارجية: خرائط (Google Maps)، بوابات دفع إلكترونية، مزودي رسائل SMS وبريد إلكتروني، ومحرك ذكاء اصطناعي للمحادثة والتشخيص. يخدم عدة فروع مستقلة مع لوحة تحكم مركزية للسوبر أدمن ولوحات تحكم لكل فرع.

**التكاملات الخارجية :**

- خدمات بوابة الرسائل النصية (SMS Gateway)
- أنظمة معالجة الدفع (Payment Gateway)
- خدمات تحديد الموقع الجغرافي (Google Maps API)

**2.2 وظائف المنتج :**

- **العميل (شخصي/شركة):** التسجيل، الدخول، إدارة الملف الشخصي والسيارات، حجز خدمات الغسيل والمساعدة على الطريق، الدفع (نقداً، باقة، نقاط)، تصفح الورش، تتبع الخدمات، الإشعارات، التقييمات، التقارير الشهرية.
- **موظف الغسيل:** عرض المهام وتصفيتها، تحديث حالة الخدمة والمواد، تأكيد الدفع النقدي، طلب مواد إضافية.
- **موظف الميكانيكي:** يرث صلاحيات موظف الغسيل، بالإضافة إلى إضافة تقارير المشاكل وطلب قطع الغيار.
- **الأدمن (مدير الفرع):** إدارة الفرع من مستخدمين وطلبات وموظفين وفواتير وتسعير ومخزون وتسويات نقدية وعقود.
- **السوبر أدمن:** إدارة شاملة لجميع الفروع والمستخدمين والأدوار والخدمات والباقات والتسعير والمخزون والعقود والسجلات والتقارير وقواعد الذكاء الاصطناعي والإعدادات العامة.
- **الممثل الزمني (Time Actor):** يُشغّل إعادة حساب السعر تلقائياً، والإشعارات المجدولة، والتقارير الدورية.

**2.3 فئات المستخدمين وخصائصهم:**

| **_الفئة_**     | **_الوصف_**          | **_المسؤوليات الأساسية_**                          | **_مستوى الخبرة التقنية_** |
| --------------- | -------------------- | -------------------------------------------------- | -------------------------- |
| زائر            | مستخدم غير مسجل      | التسجيل فقط                                        | مبتدئ (Very Low)           |
| عميل شخصي       | مالك سيارة فردي      | حجز خدمات، إدارة ملف، دفع، تقييم                   | مبتدئ (Very Low)           |
| عميل شركة       | شركة تملك عدة سيارات | صلاحيات العميل الشخصي + حجز متعدد                  | متوسط (Medium)             |
| موظف غسيل       | عامل ميداني          | تنفيذ مهام الغسيل، تحديث حالة                      | متوسط (Medium)             |
| موظف ميكانيكي   | فني متخصص            | صلاحيات الغسيل + تشخيص مشاكل وطلب قطع              | متوسط (Medium)             |
| أدمن (مدير فرع) | مدير فرع             | إدارة عمليات الفرع (مستخدمين، طلبات، مخزون، مالية) | مرتفع (High)               |
| سوبر أدمن       | مدير النظام العام    | تكوين كامل ومراقبة شاملة                           | مرتفع جداً (Very High)     |

**2.4 بيئة التشغيل :**

**جانب العميل:** تطبيق جوال (Android / iOS)، تطبيق ويب متجاوب مع جميع المتصفحات الحديثة.

**جانب الخادم:** خلفية سحابية مع REST APIs.

MySQL (علائقية) **قاعدة البيانات :**

**خدمات خارجية:** مزودي اتصالات سوريين، بوابة دفع (Payment Gateway) Google Maps API.

**2.5 قيود التصميم والتطبيق :**

- دعم اللغتين العربية والإنجليزية (واجهة وإشعارات).
- تشفير جميع البيانات أثناء النقل باستخدام TLS 1.2+.
- تشفير البيانات الحساسة (كلمات المرور، معلومات الدفع) عند التخزين.
- تحديث موقع GPS المباشر كل 5 ثوانٍ كحد أقصى.
- قابلية النظام للتوسع لدعم عدة فروع وآلاف المستخدمين المتزامنين.

**2.6 الافتراضات والاعتماديات :**

- جهاز العميل يدعم GPS والإنترنت.
- بوابة الدفع الخارجية موثوقة وتلتزم بمعايير PCI-DSS.
- مزودو الرسائل القصيرة والبريد الإلكتروني متاحون بوقت استجابة مقبول.
- يتم تدريب الموظفين والإداريين قبل التشغيل.

**4\. متطلبات الواجهات الخارجية :**

**4.1 واجهات المستخدم :**

- **تطبيق الجوال:** واجهات أصلية على Android و iOS تدعم العربية والإنجليزية (RTL كامل).
- **تطبيق الويب (للمنشآت):** تصميم متجاوب (Responsive) يعمل على جميع المتصفحات الحديثة.
- **لوحات التحكم (Admin & Super Admin):** تخطيطات Dashboard مع جداول، رسوم بيانية، خرائط، ومكونات بحث/تصفية متقدمة.
- **الإشعارات:** تنبيهات داخل التطبيق (In-App)، رسائل SMS، وبريد إلكتروني حسب تفضيلات المستخدم.

**4.2 واجهات الأجهزة:**

- مستقبل GPS على أجهزة الجوال لتحديد المواقع والملاحة.
- كاميرا لالتقاط صور السيارات ورفع الصور (للعميل والموظف).

**4.3 واجهات البرمجيات :**

- **واجهة الخرائط:** تكامل مع Google Maps أو OpenStreetMap للتشفير الجغرافي والتوجيه وعرض الخريطة.
- **بوابة الدفع:** REST API مع مزود خارجي آمن (متوافق مع PCI-DSS).
- **بوابة الرسائل القصيرة (SMS):** API لإرسال رموز التحقق والتنبيهات.
- **خدمة البريد الإلكتروني:** SMTP/API للبريد الإلكتروني.
- **محرك الذكاء الاصطناعي:** API داخلي أو خارجي للمحادثة الآلية وتشخيص المشاكل.

**4.4 واجهات الاتصالات :**

- جميع الاتصالات بين العميل والخادم عبر REST APIs مشفرة بـ HTTPS (TLS 1.2+).
- تتبع الموظف المباشر عبر WebSocket أو تحديثات دفع (Push Notifications) للتحديث اللحظي.
- الوصول إلى قاعدة البيانات عبر بروتوكولات داخلية آمنة فقط.

**6\. متطلبات أخرى :**

**6.1 المتطلبات القانونية والامتثال :**

- يجب أن يلتزم النظام بلوائح حماية البيانات المحلية المتعلقة بالمعلومات الشخصية.

- يجب أن يتوافق النظام مع متطلبات هيئة تنظيم الاتصالات السورية (إن وجدت).
